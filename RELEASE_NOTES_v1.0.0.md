## First public release

This release presents the completed network-based public-transport accessibility and spatial-equity assessment for Lagos State.

### Included

- Lagos State and 20 LGA boundaries
- 219 core bus and rail access points
- 348 multimodal transport access points
- Node-level network walking times
- WorldPop 2020 population surface
- LGA accessibility and underserved-population tables
- Final accessibility, deficit and planning-priority maps
- Network-reproduction and results-validation scripts
- Results-review notebook
- Methodology, limitations and reproducibility documentation
- Automated GitHub Actions validation

### Principal findings

Of the 11.61 million people analysed, 6.21 million (53.44%) were within a 30-minute network walk of a core bus or rail point, while 5.41 million (46.56%) were underserved.

Alimosho recorded the largest absolute deficit with approximately 967,347 underserved residents. Badagry, Epe, Ojo, Ibeju Lekki and Ikorodu formed the very-high-priority group.
